# iso_metric_fasteners — ISO metric fastener features

Through holes, cap/button-head counterbores, hex and square nut traps, and heat-set insert bosses for M2–M6.

- **Nominals**: `spec.json` (single source of truth; `iso_metric_fasteners.consts.scad` is generated — never hand-edit)
- **Verified by**: `npm run verify` compiles `test.scad` and measures every assertion; see `reports/iso_metric_fasteners.json`
- **Provenance**: see the repo's `SOURCES.md`
- **Fit gauge**: print `gauge.scad` and check which fit class actually fits your printer
