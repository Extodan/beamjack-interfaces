# bearing_iso15 — ISO 15 deep-groove ball bearing seats

Press and clearance seats, shoulders and retaining lips for 608, 625, 6001 and 6002 radial bearings.

- **Nominals**: `spec.json` (single source of truth; `bearing_iso15.consts.scad` is generated — never hand-edit)
- **Verified by**: `npm run verify` compiles `test.scad` and measures every assertion; see `reports/bearing_iso15.json`
- **Provenance**: see the repo's `SOURCES.md`
- **Fit gauge**: print `gauge.scad` and check which fit class actually fits your printer
